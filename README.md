# DayCraft

A tiny daily tracker for Shoulds, Coulds and Shouldn'ts, with a little companion creature whose health follows your week.

Live: https://rafytaf.github.io/daycraft/ — open it in Safari on iPhone, tap Share, then "Add to Home Screen".

Your logs are saved only on your device (localStorage). Nothing is sent anywhere.

Development: `npm install`, `npm run dev`; `npm run build` builds to `dist/`, which is copied to `docs/` for GitHub Pages.
